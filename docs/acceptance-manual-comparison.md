- 人工近30天使用订单时间，系统使用出库／发货时间。人工表的实际统计截止日没有可靠记录，不能确认与系统窗口完全一致。
- 系统当前窗口为2026-08-13至2026-09-11，去年同期为2025-08-13至2025-09-11；本次各款去年后续周期为2025-09-12至2026-01-31。
- 人工需求可能包含运营判断；系统为已确认公式的计算结果。差值用于核对，不代表误差率或人工／系统谁正确。
- 差值统一为系统减人工。留空不按0计算；汇总仅在该组全部SKU有数值时显示。帽款的系统历史值是查询结果，未写入交付表。
