# 架构与流程

## 模块职责

```text
src/stocking_sheet_sync/
├── bootstrap.py                 # 组装服务、管理资源生命周期
├── settings.py                  # 环境变量、运行配置、业务规则视图与校验
├── logging.py                   # 日志设置
├── entrypoints/                 # Webhook与统一CLI及子命令
├── services/
│   ├── sync.py                  # 任务协调、去重、填充状态和通知
│   ├── copies.py                # 三份复制及交付来源决策
│   ├── fill.py                  # 新老品分流、历史与预测共用写入执行器
│   ├── sales.py                 # 当前历史销量检查
│   ├── calculation.py           # 三段历史查询、预测输入与结果
│   └── notification.py          # 通知卡片内容
├── domain/
│   ├── models.py                # 任务、文件、填充状态
│   ├── products.py              # 商品识别、匹配与件数校验
│   ├── periods.py               # 去年同期及季节周期
│   ├── forecast.py              # 同比、占比分配与取整
│   └── sheets/                  # 表格解析、结构计划、数值计划和校验
└── infrastructure/
    ├── feishu/                  # 认证请求、多维表、云空间、电子表格
    ├── warehouse.py             # 商品、出库明细与京东固定/任意周期查询
    ├── redis.py                 # 批次与阶段持久化、锁
    └── artifacts.py             # 本地文件容量和数量清理
```

入口处理参数、认证和返回值。应用服务编排任务。领域层只处理输入数据，不读取配置文件、不请求飞书/数仓/Redis。基础设施负责外部IO。配置在应用边界加载后以字典或对象传递。

`bootstrap.build_service` 为 Webhook 和手动重搬组装同一服务，资源由 `ExitStack` 管理，初始化失败和正常退出都会释放连接。

## 完整处理流程

1. 读取指定多维表记录，检查必需字段并解析电子表格或Wiki链接。
2. 根据记录ID、真实表格token和可选强制请求ID寻找批次。
3. 冻结文件夹、四项填充开关、文件名和批次时间。
4. 创建原始备份，再复制为处理备份。
5. 定位唯一工作表，读取值、公式和布局快照，识别商品与新老品。
6. 按开关查询需求表SKU；历史和预测使用同一批次日期。
7. 在内存生成结构和数量计划，核对商品身份、数据覆盖及已有内容。
8. 共用执行器补列、回读校验、写数量与必要合计，再全量核验。
9. 保存交付决定：成功交付处理备份，填充失败交付原始备份。
10. 复制到交付目录，保存结果并按配置通知。
11. 在释放任务锁前清理本地临时文件。

## 三份文件

| 文件 | 文件夹 | 命名 |
| --- | --- | --- |
| 原始备份 | 备份目录 | 原表名-批次时间-原始备份 |
| 处理备份 | 备份目录 | 原表名-批次时间-填充完成/填充未完成/未填充 |
| 交付表 | 交付目录 | 配置前缀+原表名，默认前缀为市场部- |

原表不参与程序写入。失败后的处理备份保留已有写入现场，交付内容取决于已保存的交付决定。

## 去重与恢复

普通任务以记录ID和真实源表token去重。源表内容变化但token不变时，普通触发复用已有结果；需要重新计算时使用 `rerun`。

强制重搬是一个独立批次，包含同样的复制、填充和交付流程。相同 `request-id` 恢复同一批次，不生成另一组文件。复制、填充和交付占位分别持久化；写请求结果未知时停止，避免重复复制或覆盖。

Redis 去重记录永久保存。运行锁有独立有效期，当前不自动续期。批次冻结四项填充开关，修改环境变量不改变已保存批次的结果。

`running` 表示执行中或结果尚未确认；`completed` 表示阶段结束；`retryable` 表示来源暂不可用；`needs_review` 表示需要核验。展示状态还包括 `disabled`、`skipped` 和 `unsupported`。填充降级属于搬运成功，搬运本身失败单独返回失败。
